# ZETA Architecture

## Mission

ZETA is a locally hosted autonomous AI assistant.

Its objectives are:

- Think
- Plan
- Act
- Learn
- Recover
- Improve

---

# Supervisor

Responsible for system health.

Checks:

- Core
- Ollama
- Memory
- Services

Can:

- Restart
- Recover
- Repair

Never decides long-term goals.

---

# Executive Brain

Responsible for decisions.

Loop:

Observe

↓

Plan

↓

Prioritise

↓

Execute

↓

Reflect

↓

Learn

↓

Repeat

---

# Planner

Chooses the highest-priority goal.

---

# Goals

Stores active objectives.

Example:

Keep radio online

Create playlists

Publish social posts

Backup memory

---

# Scheduler

Determines when goals should run.

---

# Reflection

Records outcomes.

Successes

Failures

Retries

---

# Learning

Updates future behaviour using previous experience.

---

# Skills

Radio

Email

Calendar

Documents

Web

Social

Streaming

Each skill performs work.

The Executive Brain decides which skill to use.
